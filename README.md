# @amlplugins/hubspot-crm-deals

Native `@hubspot/api-client` SDK re-exported under the `@amlplugins` namespace.

> HubSpot CRM Deals — pipelines, stages, deal properties, associations, search.

## Install

```bash
npm install @amlplugins/hubspot-crm-deals
```

## Use

```ts
import { /* named exports from @hubspot/api-client */ } from "@amlplugins/hubspot-crm-deals";
// or
import sdk from "@amlplugins/hubspot-crm-deals";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
